API Documentation

User State API

  • Signup POST /signup/

    Registers a new user.

  • Login POST /login/

    Logs in a user with email and password.

  • Update User State POST /updateUserState/

    Updates the user state in the backend.

  • Get User State GET /getUserState/

    Retrieves the current state of a user.

Task API

  • Generate Conditional Task GET /generateConditionalTask/

    Generates conditional statement tasks.

  • Generate De Morgan Task GET /generateDeMorganTask/

    Generates De Morgan's Law tasks.

  • Generate Truth Table Task GET /generateTruthTableTask/

    Generates truth table tasks.

  • Add Task POST /addTask/

    Adds a new task to the database.

  • Delete Task DELETE /deleteTask/{id}

    Deletes a task from the database.

  • Get Task GET /getTask/{difficulty}

    Retrieves tasks of a specific difficulty (easy, medium, hard).

Admin Page

  • Admin Page GET /admin/

    Accesses the admin page where tasks can be managed.

  • API Documentation GET /admin/api/

    Displays this API documentation.
